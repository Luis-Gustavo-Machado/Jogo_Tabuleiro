# Jogo da Velha em Python

## Sobre o projeto
Este projeto consiste no desenvolvimento de um jogo da velha executado no terminal, utilizando a linguagem Python.

O objetivo é permitir que dois jogadores disputem partidas, com um sistema de campeonato melhor de 3 ou melhor de 5.

## Funcionalidades
- Menu principal interativo.
- Partidas para dois jogadores.
- Tabuleiro organizado em matriz.
- Identificação automática de vitória e empate.
- Campeonato melhor de 3 ou melhor de 5.
- Placar acumulado das partidas.
- Estatísticas dos jogadores.

## Tecnologias utilizadas
- Python
- Git e GitHub
- Visual Studio Code

## Como executar
1. Tenha o Python instalado no computador.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no Visual Studio Code.
4. Execute o arquivo Python pelo terminal.
